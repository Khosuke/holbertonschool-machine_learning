# Project : Linear Algebra

## Task 0. Slice Me Up
This task introduces Python list slicing. It demonstrates how to retrieve subsets of a list by specifying start and end indices, allowing us to access the beginning, middle, or end of a sequence efficiently.
- File: [0-slice_me_up.py](0-slice_me_up.py)

## Task 1. Trim Me Down
Here we learn how to combine iteration and list slicing to manipulate matrices. This exercise demonstrates how to traverse each row of a two-dimensional list and create a new matrix containing only the selected columns.
- File: [1-trim_me_down.py](1-trim_me_down.py)
